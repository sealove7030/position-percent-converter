位置のpx→％変換ツール

VS Codeで開く方法
1. ZIPファイルを解凍します。
2. VS Codeで「ファイル」→「フォルダーを開く」を選び、このフォルダを開きます。
3. index.htmlを開きます。
4. ブラウザで確認する場合は、Live Serverを使うか、index.htmlをブラウザで開きます。

入力できる位置
left・rightは親要素の幅、top・bottomは親要素の高さを基準に％へ変換します。
rightとbottomは、要素の右端・下端から親要素の端までの距離です。

ファイル構成
index.html       画面のHTML
css/style.css    デザイン
js/script.js     pxから％への計算とCSS出力
